PDF 转 Markdown

使用 Docling Heron INT8 分析版面、PP-OCRv6 small 识别文字，并用 TableFormer Accurate 提取表格，导出 Markdown。公式不识别。

首次下载

Heron INT8 约 68.5 MB，OCR 模型及字典约 31.2 MB；遇到表格时再下载 TableFormer Accurate 约 381.5 MB。模型合计最多约 481.3 MB，另需 PDF.js、OpenCV 和 ONNX Runtime 运行组件。

仅在点击开始后下载；浏览器允许时会缓存到本机。文件内容不会上传到模型服务。

逐页识别文字与表格，公式区域会跳过，图片不导出。扫描 PDF 也可处理；加密文件请先解密。多栏阅读顺序、复杂合并单元格和低清扫描件需要核对，Markdown 表格不保留跨行跨列。建议在电脑上处理短文档。

模型从 ModelScope 下载。Heron 与 TableFormer 使用本站维护的固定版本模型镜像。

选择文件后开始。首次使用需要联网加载组件。

使用指南

操作步骤

  1. 选择不超过100MB、50页的PDF。
  2. 逐页下载模型、分析版面并提取文字和表格。
  3. 核对阅读顺序、未匹配文字与跳过公式提示，下载Markdown。

下载与限制

模型总计最多约481.3MB，表格模型按需加载。公式不识别，图片不导出。复杂排版和扫描件需要核对；加密PDF请先解密。

本地处理

文件和输入内容在浏览器中处理。离开页面前，请下载或复制需要保留的结果。

首次运行可能需要联网下载组件或模型，关闭页面会停止当前任务。浏览器缓存可能被系统清理，届时需要重新下载。
