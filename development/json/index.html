JSON 格式化

在本地浏览器中校验、格式化和压缩 JSON。

使用指南

操作步骤

  1. 粘贴 JSON。
  2. 选择格式化或压缩。
  3. 复制处理结果。

下载与限制

仅接受标准 JSON，不执行输入中的代码。

输入示例

输入 {"hello":"world"}，点击“格式化”可查看按两空格缩进的结果；点击“压缩”可去除不必要的空白。

提示输入无效怎么办？

请检查属性名和字符串是否使用英文双引号、逗号是否多写或漏写，以及大括号和方括号是否成对。JSON 不支持注释或末尾多余的逗号。

数据会保存吗？

JSON 工具不主动上传或持久保存输入与结果，离开页面前请自行复制需要保留的内容。

本地处理

文件和输入内容在浏览器中处理。离开页面前，请下载或复制需要保留的结果。
