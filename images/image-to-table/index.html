图片提取表格

上传表格图片，选择快速或精确模式，在浏览器中预览和校对识别结果，导出保留合并单元格的 Excel 或 Markdown。

将图片拖到这里，或点击选择

支持 JPG、PNG、WebP，单张不超过 50 MB、4000 万像素。请裁剪为一个完整表格。

识别模式

快速模式首次下载合计约 78.2 MB（模型与字典 39.0 MB，运行组件约 39.2 MB）。已缓存的文件无需重复下载；实际传输量会因压缩而变化。

模型从 ModelScope 下载。精确模式使用本站维护的固定版本模型镜像。

使用指南

操作步骤

  1. 拖拽或选择一张裁剪完整、方向正确的表格图片。
  2. 选择快速或精确模式，确认下载提示后点击开始识别。
  3. 对照原图核对合并关系，双击单元格或使用输入栏校对文字，下载 Excel、Markdown、CSV 或结构 JSON。

下载与限制

快速模式模型与字典约 39.0 MB，精确模式约 412.7 MB，均需运行组件；首次下载总量见模式提示。Excel 保留识别的合并单元格，Markdown 和 CSV 的文字只放在合并区域左上角。复杂排版、低分辨率和手写内容可能识别失败，请核对结果。

快速模式使用 SLANet+，精确模式使用 TableFormer Accurate，两者均结合 PP-OCRv6 small 识别中文、英文和数字。仅下载所选模式需要的模型。两种模式均可能识别错误，请核对结果。

转换前显示占位表格，转换时加载编辑器。识别后双击单元格或在上方输入栏修改文字，支持复制粘贴、撤销重做、合并选区与取消合并。所有下载格式均使用当前编辑内容。合并多个非空单元格时，文字按行列顺序合并并换行。

Excel（.xlsx）保留当前跨行、跨列合并关系；Markdown 和 CSV 无法表达合并单元格，文字仅写入左上角。Markdown 将第一行作为表头。结构 JSON 保留当前合并信息；重新合并或拆分后无法沿用的原图坐标将被省略。

Excel 导出组件约 0.94 MB，仅在首次点击下载 Excel 时加载。

本地处理

文件和输入内容在浏览器中处理。离开页面前，请下载或复制需要保留的结果。

首次运行可能需要联网下载组件或模型，关闭页面会停止当前任务。浏览器缓存可能被系统清理，届时需要重新下载。
